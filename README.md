# README – Projet de vision industrielle

## Installation

Après avoir téléchargé ou cloné le projet, ouvrir un terminal dans le dossier principal du projet et exécuter :

```bash
pip install -r requirements.txt
```

## Lancement de l'application

Une fois les dépendances installées, lancer la plateforme Streamlit avec :

```bash
streamlit run app.py --server.maxUploadSize 500
```

## Accès à la plateforme

Après le lancement, Streamlit affiche une adresse locale dans le terminal.

Ouvrir cette adresse dans un navigateur pour accéder à la plateforme.

## Remarque

Les commandes doivent être exécutées depuis le dossier principal du projet contenant notamment :

* `app.py`
* `requirements.txt`
